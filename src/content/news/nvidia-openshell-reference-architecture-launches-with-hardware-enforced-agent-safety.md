## NVIDIA OpenShell Reference Architecture Now Available

NVIDIA announced the OpenShell Reference Architecture on October 21, 2026 at GTC Berlin. The architecture brings together NVIDIA Vera Rubin infrastructure for model inference, NVIDIA Vera CPUs for agent harnesses and tool use, and NVIDIA BlueField-4 DPUs running NVIDIA Sentry for in-silicon enforcement.

## Performance and Safety Specifications

NVIDIA Vera Rubin NVL72 systems deliver 30x higher throughput per megawatt for agentic workloads. NVIDIA Vera CPUs deliver 2x the performance of x86 processors with greater energy efficiency.

NVIDIA BlueField-4 DPUs running NVIDIA Sentry can quarantine and stop an agent that moves outside its software boundary in milliseconds. NVIDIA Sentry, powered by DOCA and running on BlueField-4, boosts agent capacity by up to 20%.

## Enterprise Adoption and Governance

ServiceNow announced the general availability of ServiceNow Arc, a personal long-running AI agent with actions governed at runtime by the ServiceNow Super Intelligence Control Tower and enforced by NVIDIA OpenShell.

ServiceNow's AI Passport authority layer allows enterprises to revoke an AI agent's access across software and hardware within seconds.

## Industry Partners

NVIDIA system manufacturers Dell Technologies, Cisco, HPE, Lenovo and Supermicro are among those building infrastructure with the OpenShell Reference Architecture.

European banks BBVA and Santander are working with NVIDIA to explore the OpenShell Reference Architecture as a framework for strengthening agent safety, security and governance.
