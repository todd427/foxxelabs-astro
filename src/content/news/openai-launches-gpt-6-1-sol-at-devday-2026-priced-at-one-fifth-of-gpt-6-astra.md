## OpenAI's New GPT-6.1 Sol Model

OpenAI announced GPT-6.1 Sol at DevDay 2026, positioning it as an update to GPT-6 Sol aimed at coding, computer use, and professional tasks. The company states that GPT-6.1 Sol approaches GPT-6 Astra on several evaluations.

The model introduces compelling economics for developers. GPT-6.1 Sol is priced at one-fifth of GPT-6 Astra's standard input and output token prices. For context, GPT-6 Astra costs $10 per million input tokens and $50 per million output tokens, while GPT-6.1 Sol's cached input costs $0.10 per million tokens.

GPT-6.1 Sol is available through the API, ChatGPT Work, and Codex.

## Expanded Agents and Automation Capabilities

OpenAI's Agents API now supports computer use, allowing applications to operate software through graphical interfaces. The Agents API incorporates multi-agent capabilities from Codex, tool search, tool calling, and context compaction.

Codex has expanded its deployment options. It can now run in cloud environments in addition to local computers, allowing developers to start remote tasks from other devices.

OpenAI updated the Codex CLI with voice input and an /agents interface for delegating and monitoring multiple tasks. A new Codex code-review workflow can analyze diffs and potential issues in GitHub pull requests and GitLab merge requests.

Codex Security Cloud can scan repositories and new commits, investigate findings, remove duplicates, and prepare fixes.

## New Decision-Making and Collaborative Tools

OpenAI announced a Decisions API, currently in limited preview, which uses the smaller Luna model to select from a predefined set of answers based on text or image context. OpenAI positions the Decisions API for tasks such as classification, request routing, and choosing an agent's next action.

OpenAI introduced Dots at DevDay 2026, described as persistent agents that can work on ongoing tasks. The company also introduced ChatGPT Space, described as a shared workspace where teams and agents can work with common context.

## Broader AI Market Developments

Google touted Gemini 4 Argon as performing better than top OpenAI and Anthropic offerings in some benchmarks. Gemini 4 Argon is being rolled out cautiously, starting with cybersecurity partners.

In leadership news, Demis Hassabis stepped down as CEO of DeepMind in August 2026, with Koray Kavukcuoglu taking over as the new head.
