## OpenAI Deprecating Prompt API

OpenAI is deprecating reusable prompt objects in the API, with prompt creation to be de-emphasized beginning June 3, 2026. The v1/prompts endpoint is scheduled to shut down entirely on November 30, 2026.

Developers currently relying on OpenAI's prompt management features should begin planning migrations away from the v1/prompts endpoint before the sunset date.
