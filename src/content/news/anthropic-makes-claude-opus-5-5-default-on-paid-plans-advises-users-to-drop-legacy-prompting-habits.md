## Claude Opus 5.5 Becomes Default for Anthropic Paid Users

Anthropoc has made Claude Opus 5.5 the default model on paid plans. The company simultaneously published a guide addressing a critical discovery: common prompting habits carried over from older models actually slow Claude Opus 5.5 down.

According to Anthropic's guidance, dropping phrases like 'think hard' and starting at Medium effort gets faster results with no quality loss in Claude Opus 5.5. This marks a significant shift in how users should approach prompting the latest version—what worked before may now be counterproductive.

## Google Brings Website Generation to Gemini Notebook

Google's Gemini Notebook now lets users type a single sentence to generate a live, shareable website built from their notes and sources. The website-generation feature is rolling out to all users aged 18 and above on the web version.

## BRIDGE Preprint Reveals Memory Trade-offs in AI Agents

The BRIDGE preprint reports that simple notes plus hybrid keyword and vector retrieval can match strong memory systems on standard recall benchmarks when the answering model is held constant.

The research found nuanced differences in how memory formats perform. Memory built from separate facts did better at applying stated rules, while summaries of conversation blocks did better at following demonstrated patterns. Notably, the preprint found cases where the correct rule was retrieved by an agent but ignored—changing the rule's presentation closed much of that gap.

## LangSmith Retains Complete, Unredacted Traces

LangSmith retains complete, unredacted traces; restricting who can view a prompt does not prevent its collection or shorten retention. This is a critical privacy consideration for teams using the platform.
